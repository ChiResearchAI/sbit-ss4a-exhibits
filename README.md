# sbit-ss4a-exhibits

Method exhibit accompanying ChiResearch Technologies, LLC's proposal for
**Component A — Safety Analysis**, Shoalwater Bay Indian Tribe RFP P-2027-2,
SS4A Safety Action Plan.

**Counting Before Mapping** — what the federal crash record can and cannot
support for a High-Injury Network on the Shoalwater Bay Indian Reservation.

Built from NHTSA's Fatality Analysis Reporting System national releases
2019–2023 and the Tribe's own *Shoalwater Bay Indian Tribe Safety Plan* (May 2017).
Single self-contained page, no build step and no dependencies.
